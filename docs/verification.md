## 자동 검증 범위

- Node: 전체 교재·목표/문항/출처 연결, 구조·정답 ID·고유 보기·무해한 출처 URL, 복습 간격·추측/힌트·중복 시도, 시험 기한·미응답·점수, 600개 시드의 범위·주차 균형·보기 순열, 선수 연결의 순환 없음.
- 저장: 손상/미지원 버전/알 수 없는 필드/과대 백업/잘못된 날짜/프로토타입 필드, 권한·할당량 오류, 다른 탭 변경, 복원 전 검사, 지속 readback 오류의 불확실 상태, 다른 앱 키 보존.
- 로컬 서버: dist 밖 파일 거부, HEAD/POST, 인코딩 오류·경로 탈출 요청, 오류 뒤 정상 자료 제공.
- 실제 브라우저 21개 시나리오: 네 단계 학습·새로고침, 문제 정답/확신/힌트, 시험·시간 경과·자동 제출·표시·결과, 백업 검사·다운로드·복원·취소·초기화, 충돌/할당량/손상, 320px·390px 주요 경로, 가상 사건 활동, 콘텐츠 HTML 실행 방지, 자료 로딩 실패 안내, 학습 경로·진단, 과거 결과 재열기, 날짜 입력 경계.
- check: 전체 배포 JS 구문, UTF-8 무BOM, 자산 연결, CSP·위험한 DOM 실행 방지, 원본 PDF/백업/비밀 파일 배포 제외.

브라우저 고장 조건은 격리된 테스트 컨텍스트에서 재현한다. 실제 사용자 기록과 환경 설정을 고장내거나 삭제하지 않는다. 시험의 60분 만료는 브라우저 내 시계를 이동해 검사했으며 사람이 실제 60분 동안 시험을 치른 검증은 아니다.

- 실제 시험 문항/배점·교수의 채점 기준과 일치율, 실제 학습자 대상 성취도 실험.
