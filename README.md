# 인터넷보안 학습실

인터넷보안의 원리를 이해하고 예제·설명·문제·복습으로 연결하는 학습 지원 앱입니다.

[학습실](https://hyungminyoon1.github.io/internet-security-study/) · [WEB LAB](https://hyungminyoon1.github.io/web-lab/#internet-security-study) · [구조](architecture.md) · [결정 기록](docs/decisions.md) · [검증 기록](docs/verification.md)

## 학습 범위

제공된 인터넷보안 교안 13개, 315쪽의 교육 내용과 페이지를 대응했습니다. 8·15주차는 사용자가 지정한 교안 범위에 포함되지 않습니다. 원본 PDF·강의 슬라이드 이미지는 공개하지 않습니다. [입력 자료 목록과 확인 범위](docs/source-inventory.md)를 별도로 기록했습니다.

| 구분 | 범위 | 개념 | 문항 |
| --- | --- | ---: | ---: |
| 중간 | 1–7주차 | 84 | 341 |
| 기말 | 9–14주차 | 60 | 290 |
| 전체 | 13개 주차 | 144 | 631 |

인터넷·계층·보안 목표, 암호·전자서명·인증서, 운영체제·계정·권한, VPN, DB 보안, 방화벽, IDS/IPS/WAF, 네트워크·시스템 공격 원리, 무선망, 웹 보안, SQL 삽입·XSS·인가, ESM 상관분석, 사고 대응·증거 해석을 다룹니다.

149개 정정·환경/버전 구분·불확실한 표현 처리 기록이 있습니다. 이는 교안의 확정 오류가 149개라는 뜻이 아닙니다. 현재 기술 기준과 구형 사례를 구분하며, 원자료를 확인하지 못한 역사 수치 등은 정답 암기 대상으로 사용하지 않습니다. 앱의 ‘범위·정정 안내’에서 페이지별 학습 연결과 공식 출처를 확인할 수 있습니다. 각 문항의 정답·보기별 이유는 새로 작성했으며 실제 시험 기출이라고 표시하지 않습니다.

2026-10-17에는 교안의 오기·정정 사실 자체를 묻던 58문항을 원리·조건·상황 판단 문제로 교체했습니다. 출제 대상은 여전히 631문항입니다. 과거 58문항의 정의는 이전 풀이·백업·모의고사 결과를 해석하기 위해서만 남기며, 새 연습·시험에는 나오지 않습니다.

## 추천 사용 순서

‘범위·정정 안내’에서 교안의 설명·검증한 내용·수정 근거를 나란히 비교하고, 검색·주차·교수님 확인 필요 필터로 항목을 찾을 수 있습니다. 관련 개념과 문제 해설에도 같은 비교가 제공됩니다. 기술 내용 정정 및 근거 미확인 81건은 실제 시험 기준에 대해 교수님 확인이 필요하며, 맥락 보완 68건은 문항의 조건·버전을 확인하도록 표시합니다. 이는 오류 건수나 공식 출제 제외 목록이 아닙니다. 원문 요약과 구체적인 대조 근거를 보강한 여섯 사례의 원고는 `tools/authoring/correction-comparisons.mjs`에 있습니다.

1. 상단에서 중간·기말 범위를 고릅니다. 처음이라면 ‘개념 학습’의 ‘시작점 찾기’로 주차별 두 문제를 풀어 보세요.
2. 여섯 질문형 학습 경로나 주차별 목록에서 시작합니다. 먼저 보면 좋은 개념도 연결되어 있습니다.
3. 각 개념을 **이해 → 풀이 예제 → 스스로 설명 → 문제 적용** 순서로 공부합니다.
4. 정답뿐 아니라 모든 오답의 이유를 확인합니다. ‘확실해요/헷갈려요/추측했어요’와 힌트 사용을 복습에 반영합니다.
5. 방화벽 규칙 순서·경보 증거·사고 대응 활동으로 판단을 연습합니다.
6. 60분 모의고사(20/30/40문항)에서 답안을 제출하고 부족한 개념으로 돌아갑니다. 결과는 최근 20회 다시 열 수 있습니다.

문항과 보기 순서는 시도마다 바뀌지만 정답 ID는 유지됩니다. 모의고사는 주차별로 균형 있게 고르며 실제 시험의 출제 비중을 예측하지 않습니다. 제한시간은 사용자가 알려 준 60분입니다. 실제 문항 수와 객관식 여부는 확정되지 않았으며 기본 30문항은 연습 설정입니다.

읽기 완료와 이해 확인은 별개입니다. 다른 유형의 문제를 하루 이상 간격을 두고 확신 있게 맞힐 때만 ‘시간을 두고 확인됨’을 표시합니다. 짧은 진단·반복 정답률만으로 전체 범위 숙달이나 합격을 보장하지 않습니다.

## 기록과 안전

- GitHub Pages가 화면·문제를 제공하고, 선택한 계정 사용자는 Neon Auth + Data API + PostgreSQL로 로그인·진도를 동기화합니다. Vercel·공유 랭킹 서버·분석 추적은 사용하지 않습니다. 문제와 정답은 공개 정적 데이터이며 고부담 평가·시험 감독 서비스가 아닙니다.
- 비로그인 기록의 `internet-security-study-v1` 키는 그대로 유지합니다. 로그인은 기존 기록을 자동 업로드하거나 삭제하지 않습니다. ‘계정·동기화 → 이 브라우저 기록 가져오기’를 확인해야 계정에 합쳐집니다.
- 이메일·비밀번호로 가입하고 이메일 인증번호를 확인합니다. 이름·전화번호는 받지 않으며 필수 이름 필드에는 고정값을 사용합니다. 비밀번호·세션은 관리형 Neon Auth가 처리하고 접속 IP·브라우저 정보가 인증 메타데이터에 포함될 수 있습니다. 앱은 비밀번호·인증 토큰을 Web Storage에 저장하지 않습니다.
- 계정별 전송 대기본은 `internet-security-account-v1:<user-id>`에 분리합니다. 읽기·풀이는 합치고 북마크·설정의 상충된 변경은 선택을 요청합니다. 기기 시각이나 단순한 전체 덮어쓰기로 우선순위를 정하지 않습니다. 풀이 최근 3,000건, 모의고사 최근 20회를 보관합니다.
- 같은 계정의 모의고사는 한 기기에서 수정합니다. 다른 기기에서 ‘이어 풀기’를 확인해 넘겨받아도 이미 저장한 답안·서버 기준 마감시간은 유지됩니다.
- JSON 백업을 검사·미리보기·확인 후 복원합니다. 손상·미지원 버전은 자동으로 덮어쓰지 않습니다. 저장이 차단되면 임시 학습으로 계속하며 내보내기를 안내합니다.
- 저장 시도 후 결과를 확인할 수 없는 경우 ‘저장됨’이라고 표시하지 않습니다. 원본은 해당 탭 메모리에서 내려받을 수 있으니 새로고침 전에 보관하세요.
- 기기를 옮기기 전 계정 화면의 ‘마지막 동기화’와 대기 건수·오류 여부를 확인하세요. 연결이 끊겨 열린 화면에서 계속 공부할 수 있어도 미전송 기록은 다른 기기에서 볼 수 없습니다. 새로 오프라인 접속하는 완전한 오프라인 앱은 아닙니다.
- 로그아웃 후에도 계정별 로컬 대기본은 복구를 위해 남습니다. 공용 PC에서는 동기화·백업 후 로그아웃하고 사이트 데이터를 정리하세요. 동일 GitHub Pages 출처의 다른 코드로부터 비밀을 격리하는 저장소는 아닙니다.
- Neon Free의 사용량·메일 제한 또는 브라우저의 타사 쿠키 제한으로 계정 기능이 실패할 수 있습니다. 실패를 저장 성공으로 표시하지 않으며 비로그인 학습·파일 백업은 유지합니다. 유료 전환을 자동으로 수행하지 않습니다.
- 2026-10-17 공개 HTTPS 검증에서 Chromium·Firefox의 계정 동기화는 통과했지만 WebKit은 세션 쿠키를 유지하지 못했습니다. iPhone/Safari의 계정 동기화를 지원 확인된 것으로 보지 마세요. 해당 환경에서는 파일 백업을 사용할 수 있으며, 실제 iOS/Android 기기 검증은 별도입니다.
- 사고 활동은 가상 자료 해석뿐이며 실제 공격·패킷 수집·계정/시스템 변경을 수행하지 않습니다.

## 개발·검증

Node.js 22 이상. 공식 Neon SDK를 고정 버전으로 설치해 로컬 번들로 제공합니다. 순수 도메인·저장·DB 검증은 Node/PGlite, 브라우저 회귀는 Playwright를 사용합니다.

```sh
npm ci
npm run build
npm test
npm run check
npx --no-install playwright install chromium
npm run test:browser
npm run test:account-browser
npm run dev -- 0
```

로컬 서버는 127.0.0.1에서 dist만 제공합니다. GitHub Actions는 Windows/Linux Node 검사와 Linux Chromium 브라우저 검사를 통과한 뒤 dist만 Pages에 배포합니다. 테스트·수동 콘텐츠 검토·실제 공개 화면 검증의 범위는 [검증 기록](docs/verification.md)에서 구분합니다.

계정 동기화의 권한·API·충돌·보존 정책은 [계정 동기화 계약](docs/account-sync.md), 이번 검증의 경계는 [계정 검증 기록](docs/account-verification.md)에 있습니다. 실제 Neon 운영 검사는 일반 CI에서 실행하지 않습니다.

## 콘텐츠 수정

`tools/authoring/part-1.mjs`~`part-4.mjs`가 명시적 원고이며 `question-revisions.mjs`가 58문항 교체 원고입니다. 해당 원고를 수정한 뒤 해당 파일을 Node로 실행하여 주차 JSON을 재생성합니다. 문항을 템플릿으로 무한 증식하거나 실행 중 AI로 생성하지 않습니다. 의미·정답이 바뀌는 교체는 새 ID를 발급하고 과거 정의를 보존합니다. 보기·해설·정정 근거를 함께 검토하세요.

콘텐츠에는 [계약](docs/content-contract.md), [저작 감사](docs/content-audit-part-1.md), [독립 의미 검토](docs/peer-review-part-1.md)가 연결됩니다. 원문 전체 읽기와 핵심 도표 시각 점검을 구분하며, 자동 스키마 검사가 학술적 무오류를 증명하는 것은 아닙니다.

텍스트는 UTF-8 무BOM·CRLF입니다. 최신 계정·문항 정비일은 2026-10-17입니다. 이 학습 앱은 학교·교수·국가기관의 공식 서비스가 아닙니다.
